## 学习建议

- 不要只读文档，每学完一节就写 SQL、画表关系或实现一个小接口。
- 并发相关内容优先掌握数据库唯一约束和事务边界，再学习 Redis 锁。
- 性能优化先看执行计划和扫描行数，不要凭感觉添加索引。
- 压测时关注 P95/P99、错误率、数据库连接数、锁等待和慢查询。
- 生产配置不要直接照抄示例，必须修改默认密码、镜像版本和密钥管理方式。
